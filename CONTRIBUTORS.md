# Contributors

Thank you to everyone who made this plugin possible.

## Original author

- **Aislan Dener Souza Vicentini** ([@aislandener](https://github.com/aislandener)): created
  [galaxy-buds-control](https://github.com/aislandener/galaxy-buds-control), the protocol helper,
  the model table, the panel and the codec row. This plugin is inspired by and built on his work,
  and keeps his full history.

## Maintainer

- **Oleksii Lysenko** ([@akafrmn](https://github.com/akafrmn)): Galaxy Buds Pro line focus,
  Buds3 Pro hardware verification, Buds4 Pro support, in-case battery status, low battery warning.

## Code contributors

- **Pavel Kalashnikov** ([@kalashnikovisme](https://github.com/kalashnikovisme)): search and pair new
  earbuds from the disconnected panel (upstream #3).
- **Tom V.** ([@OverStyleFR](https://github.com/OverStyleFR)): keyboard navigation for every panel
  control.

## Protocol references

- **Tim Schneeberger** ([GalaxyBudsClient](https://github.com/timschneeb/GalaxyBudsClient)): the
  reference reverse-engineering of Samsung's SPP protocol. Read for reference, no code copied.
- **hmarquez-solutions** ([omarchy-buds](https://github.com/hmarquez-solutions/omarchy-buds)): live
  Buds4 Pro captures that confirmed the Buds4 layout and its noise-ack quirk.

## Adding yourself

Opened a merged pull request or filed a compatibility report that moved a model to "verified"?
Add yourself under the right heading in the same pull request, or ask and we will add you.
